# PAPP2 Frontend - Street Food Rating App

React Native mobile application for rating street food places. Browse nearby food spots, leave ratings, and discover the best street food in your area.

## Tech Stack

- **Framework:** [React Native](https://reactnative.dev/)
- **Language:** TypeScript

## Backend

This app connects to the PAPP2 backend API:
[PAPP2 Backend](https://github.com/99Arrzel/PAPP2)

## Getting Started

### Prerequisites

- Node.js (v16+)
- npm or yarn
- Expo CLI or React Native CLI
- Android Studio (for Android) or Xcode (for iOS)

### Installation

```bash
# Clone the repository
git clone https://github.com/99Arrzel/PAPP2FRONTEND.git
cd PAPP2FRONTEND

# Install dependencies
npm install

# Start with Expo
npx expo start

# Or run directly on a platform
npx react-native run-android
npx react-native run-ios
```

### Configuration

Make sure the backend API is running and update the API base URL in the app configuration to point to your server.
